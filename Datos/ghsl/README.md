# Datos GHSL

Datos de superficie construida (GHS-BUILT-S R2023A) utilizados para analizar la expansión urbana de São Paulo.

## Años analizados

- 2005
- 2020

## Procesamiento

Los datos originales fueron reproyectados al sistema SIRGAS 2000 / UTM zona 23S (EPSG:31983), recortados al municipio de São Paulo y transformados en una clasificación binaria de superficie urbana.

Criterio operativo utilizado:

- 1 = urbano: ≥ 1000 m² de superficie construida por píxel.
- 0 = no urbano: < 1000 m².

La resolución de análisis es de 100 m.
